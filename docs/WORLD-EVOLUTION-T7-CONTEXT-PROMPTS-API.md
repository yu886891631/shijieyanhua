# T7：上下文、提示词与 API 继承

日期：2026-10-07。基线：`codex/world-evolution-alpha14-u9`，HEAD `37362107567133fb71c023810143a5f944152c7e`。

状态：本地实现与模拟验收完成；不是新的酒馆导入包，也不代表真实演变全链已验收。

## 1. 本轮完成内容

- 提示词：全局规则常驻；阶段/表补充规则支持继承、自定义、关闭。表生命周期规则继续唯一保存于 T2 模板，不另建一份更新规则。
- 草稿、保存到内存、启用版本、运行冻结是四种状态。保存草稿不进入生成；启用后改变下一轮模拟请求，旧请求保持原版本。
- 整轮冻结已保存世界、模板、剧情、前置结果/证据、成功标记、选择条件、启用规则和 API 配置。宏观计划先确定；微观在可信阶段服务交接最新宏观私有视图后确定。
- 宏观以旧宏观为基底；微观读取本轮最新宏观和原微观状态。拒绝另一个 run、输入、世界、资料 revision，或夹带微观修改的交接。
- 稳定身份是表 ID + 行 ID。候选包含剧情关联、用户指定、关系、宏观位置影响、默认计划期限和后台轮转；不按姓名去重，不靠表中文名分类。
- 权限实际用于材料选择、字段描述、关系解析和 T3
  SQL 授权。锁定/禁更对象可读但不授权写入；隐藏 UI 列不自动成为秘密；主 AI 不可读但演变可读的列仍能进入演变请求。
- 每请求显示精确 messages、来源、行数、字符数、粗略 token、截取理由、最终路由、规则来源和版本。预览和模拟消费同一份冻结请求，不由 Vue 再拼接。
- 内置 API 复用现有
  `callWorldEvolutionApiPreset`，凭据仅留在私有闭包。模板、请求元数据、页面与响应日志不保存 Key 或认证头；错误只展示安全说明。
- 与 T4/T5/T6 共用沙盒服务：未保存资料/结构或待确认事务阻止冻结；资料/模板正式变化后发送前复查；剧情/swipe/前置结果变化使旧输入失效。

## 2. 上下文及来源适配

顺序为当前剧情、紧邻的玩家输入、配置允许的旧助手消息、明确选择的外部结果、候选旧状态与相关条件。最近助手数为 0 时不发送历史。

- SP·数据库：复用 T5 `sheet_*.content`
  表头 + 二维数据识别，明确选择表、行、列。固定 42 行样本证明按行识别；不把数据库全量导出当一个角色。
- MVU：只读选定路径，如 `stat_data.天气`；不默认发送全部变量，不写回 MVU。
- 世界书：只读选定、启用的原始条目；排除 `WorldEvolution-*`，避免把本插件旧投影再当新事实。
- 外部资料必须有独立前置状态，匹配当前聊天/世界/分支/消息/swipe/输入指纹、来源提交与结果指纹；需要持久化证据时，运行时完成不等于已保存。
- 必要来源失败、等待、无法验证、未安装或身份失配会阻断；停用/频率跳过须有本轮身份与明确理由，且不读取其旧结果。可选失败来源不参与上下文。

这里验证的是调用方提交的规范证据契约，不是可信宿主适配器或数字签名；真实插件怎样取得落盘证据、监听去重和触发所有权仍由 T8/T10 接入。未知宿主能力不能凭模拟对象称为已经支持。

## 3. 预算与受限 SQL

- 当前实现每张到期表一个请求，按模板顺序列出；总计划对象、新对象和请求分配受整轮默认预算与硬上限约束。当前预览保守预留最大对象/新增配额；按宏观实际用量回收未用配额由 T8/T9 阶段执行器接入。
- 上下文字符预算按单请求有效上限核对，包含系统规则、字段描述、messages 和授权清单；token 只是粗略估计，不保证供应商价格。
- 可选材料超限时整段省略并解释，不截断 JSON。当前剧情、玩家输入、选中旧状态或必要引用不能完整放入时阻断该请求，不发送失真内容。
- 请求读写范围编译为 T3
  policy，新增也提供字段授权。必填/默认列不可授权时不宣传能够新增。实际 SQL 测试确认可读条件不能借 UPDATE 改写。
- 模型输出要求 `{ "sql": "受限 SQL", "parameters": [] }`，绑定值采用 T2
  JSON 逻辑类型；decimal 是固定精度文本，不是 SQLite 缩放后的整数。T3 仍是类型、引用、读取/写入权限和整批校验的执行者。
- 模拟经过现有 API 客户端的请求/响应/重试逻辑，但强制注入本地假 fetch。每次假发送也检查并消费整轮及本表上限；没有回退到默认网络 fetch 的路径。
- 轮转位置是提交建议，不在预览/模拟/失败时推进。多槽预算留后台机会；单槽通常先处理直接剧情，逢第 4 个合格剧情轮保留后台轮转机会。宏观未点名行也能轮转。

自然语言事实不能仅靠结构校验自动证明。当前模拟响应不执行 SQL、不保存模型结果、不标记真实演变成功。

## 4. 页面与操作后果

`T7WorldWorkbench.vue` 把资料工作台与提示词/发送预览组合，切页使用保留挂载的视图，不自动保存或发送。

| 动作                | 后果                                                        |
| ------------------- | ----------------------------------------------------------- |
| 修改规则 / 保存草稿 | 仅改本地内存草稿，不启用、不调用 API                        |
| 启用已保存草稿      | 递增启用规则版本，只影响新冻结运行                          |
| 冻结并预览宏观请求  | 核对已保存状态、证据与配置，不联网、不写存档                |
| 查看微观计划        | 宏观未交接时只显示待确定，不伪造本轮最新条件                |
| 模拟此请求          | 调用现有客户端 + 强制本地假传输，不验证网络/Key、不执行 SQL |
| 关闭本轮预览        | 丢弃本地运行预览，不删除世界资料                            |

UI 沿用淡绿卡片和粉红阻断提示、私有 scoped 样式、响应式列及安全文本渲染。真实宿主页面/键盘/100%–125% 几何验收未执行。

本地规则配置没有接宿主持久存储，关闭/刷新会丢失配置及草稿，页面有明确提示。API 路由来源由同一 T2 模板解释，本轮未再做一套独立凭据编辑器。
