# T12：世界书配置、隔离与精确投影

日期：2026-10-09。范围：新 SQL 工作台的本地实现、模拟世界书和模拟主 AI 上下文捕获。没有安装到 alpha.16 旧入口，没有修改实际角色卡世界书。

## 1. 本阶段交付

新增统一投影链：

```text
T4/T10 独立确认的当前正式存档
  → 当前已保存模板的导出参数
  → 主 AI 可见性过滤 / 稳定键 / 不可变代际
  → 实时世界书差异 + 明确范围确认
  → 带源版本检查的受控同步
  → 独立读回完整代际
  → 受控捕获同一代际的主 AI 上下文
```

代码分工：

- `t12-projection.ts`：纯投影、稳定键、SHA-256 指纹、目标解析和严格代际校验。
- `t12-gateway.ts`：能力契约、托管归属、精确差异、完整代际读回检查、只读适配器。
- `t12-simulated-book.ts`：独立 JSON 假世界书、共享同步/捕获边界、源存档 fence、故障注入。
- `t12-controller.ts`：检查、查询、同步、仅投影重试、修复、逻辑重建、只读状态与受控捕获。
- `T12ProjectionWorkbench.vue`：投影页面，淡绿资料区与粉色范围确认区。
- T11 增加可选投影状态订阅：总览收到投影变化通知，不另存一套“已同步”标志。

不调用演变 API，不执行新的 SQL，不追加世界提交，不反向用世界书补猜表格。表级导出配置直接取 T6 保存的模板，页面仅显示并导航到同一份配置，没有复制第二套设置。

## 2. 只读取已确认、有效的正式版本

投影从存档网关独立读取，并完整验证 T4 存档链、世界/聊天/分支与正式提交头；T4 私有草稿不进入导出。保存回执不明或正在保存时阻断。

已明确初始化并由沙盒权威确认的 genesis 也可投影，显示为“已确认初始化快照”，不是伪造一个 AI 提交。采用模板本身不生成资料；空表不会创建占位世界书条目。

T10 模式还要求恢复服务证明
`ready`、有效源头和同一角色卡身份。未知/未验证来源、损坏链、仅只读的失效祖先不能直接投影；先核对或通过统一服务明确恢复正式版本。不能把普通内存 getter、旧 IndexedDB 或缓存账本作为替代权威。

任务固定绑定
`chatId + worldId + branchId + commitId/初始化头 + characterId + primaryBook`，并包含正式状态指纹。同步、查询、重试和捕获均重新核对。切聊天/角色卡/分支/主世界书后，旧任务不会自动采用新目标；需重新检查生成当前范围的任务。

## 3. 统一的导出与可见性

同一模板导出配置的三种模式：

| 模式       | 条目内容                             | 激活方式                     |
| ---------- | ------------------------------------ | ---------------------------- |
| `per-row`  | 每条记录一个条目，所选公开字段为正文 | 安全的非空关键词触发（绿灯） |
| `index`    | 每张表一个允许公开的标题目录         | 常驻（蓝灯），不包含整表正文 |
| `constant` | 每张表一个所选字段的整表正文         | 常驻（蓝灯）                 |

表、行、字段均须允许主 AI 读取；关闭导出、空表、归档过滤和无可导出正文均不制造占位条目。演变停用/锁定不自动抹掉允许读取的资料。归档是否导出使用
`includeArchived`。

标题、关键词、索引和正文使用相同的主 AI 权限。引用只解引用允许读取的目标标题，不输出秘密目标姓名、稳定 ID、隐藏目标数量或可推断的替代名称；循环引用有界，不使用
`[object Object]`。数字、布尔、NULL、列表与世界时间使用既有类型，时间显示采用模板保存的世界时间，不读取现实时间。

用户预览另取“主 AI 可读 ∩ 用户可读 ∩ 非隐藏 UI 列”。主 AI 获准读取不意味着用户获准预览；没有权限的正文不从旧世界书条目绕回来。实际差异可显示受限制条目的汇总/操作，但不公开其旧正文、秘密标题和身份。UI 隐藏与主 AI 保密是两个不同开关。

逐行导出缺少可公开关键词时失败关闭，不静默改成常驻。超长正文/标题/关键词或整批超限时整批阻断，不截断一半资料。检测到
`<%` 或 `{{`
执行标记时拒绝导出，避免宿主模板/宏插件把资料当代码；Vue 预览始终转义文本。凭据保险库可注入保护字符串，输出与已打开的预览也会检查/脱敏，不读取或复制 API 设置。

这不是自动证明任意剧情文字的语义保密：若用户把秘密自行写进一个公开字段，字段授权本身不能识别所有自然语言推断。主 AI 请求实际过滤和宿主扩展处理仍须后续指定范围验证。

## 4. 稳定身份、归属与精确差异

稳定键使用 `[chatId, worldId, branchId, tableId, rowId]`；整表/索引的 `rowId`
为 NULL。姓名、表显示名、SQL 名和条目显示标题均不是身份。改名更新原 UID，不另建同名对象；同名 NPC、组织、不同表、不同聊天/分支不合并。

新托管元数据独立放在
`extra.world_evolution_sql_t12`：协议版本、完整范围、角色卡、稳定键、表/行、源头、代际及内容指纹。指纹覆盖正文、标题、关键词、概率、递归、位置和效果配置；实时检查不只相信
`extra` 里缓存的指纹。

SHA-256 与严格格式用于检测损坏和版本冲突，不是服务器签名或身份认证。只处理严格匹配新协议的托管范围，不根据
`WorldEvolution-*` 名称、旧 `managedBy` 或 UID 猜删除权。

- 当前世界：新增缺失、原 UID 更新漂移、清理其已取消导出/删除/归档过滤产生的孤儿，以及同键重复条目。
- 同书其他世界：只停用新协议的本插件条目，保留资料；不会删除它们的世界存档。
- 用户、TavernDB、MVU、其他插件与归属不明的旧条目：保留内容与激活状态。
- 启用中的归属不明 `WorldEvolution-*`
  条目：无法证明它们不会串入主 AI，阻断投影，不擅自接管或停用。T13 另做明确迁移预览。

逻辑“重算全部托管投影”重新从当前正式版本生成和检查受控范围；不是清空整本书，也不会无变化时重新分配 UID。新元数据与更新保留条目的其他
`extra` 内容。

## 5. 一致代际、失败与仅投影重试

同步只接受明确具备下列能力的注入驱动：独立持久读回、受控世界书 CAS/同步边界、受控主 AI 捕获边界、源存档版本 fence，以及所声明范围的证据。设置页面或用户 JSON 不能把普通 getter 升级为这些能力。

模拟实现使用同一假世界书权威实例的共享队列，覆盖两个控制器的写入及整个上下文捕获。最后一次源检查还比较可信假存档的完整序列化版本，写入前同步检查源与整本书没有变化：另一个实例保存新世界、或用户修改世界书，都不会被旧任务覆盖。没有注册可信源的模拟驱动也拒绝操作。

这是**模拟权威的证明**，不是生产环境用一个模块 `Map`
就有跨 iframe/标签页/设备互斥。真实驱动必须提供等价、经过验证的边界；首版不承诺多设备协同，也不把“不同时开两窗口”的口头约定当锁。

同步模拟分为撤下旧代际、暂存受控条目、完整激活及独立确认。部分失败时托管投影保持停用/阻断，不放行混合新旧版本。读回须确认完整条目、实际载荷、激活设置、代际、源头及其他世界停用情况。

- 明确写失败：世界正式提交保留；仅投影重试，不重演、不重复 SQL、不重复推进时间。
- 回执丢失：先独立查询；如果已完整落盘，不再次写入。
- 部分写入：主 AI 捕获阻断；当前有效源的显式重试修复条目，保留已有稳定 UID。
- 读回失败：显示未确认，不保留缓存中的“已同步”结论。
- 源/目标过期：旧重试拒绝，不偷偷换目标书。
- 主 AI 捕获：重新验证当前源与完整代际；锁覆盖资料捕获期间，捕获中切世界/撤权限或出现非协调变更则丢弃捕获结果。捕获回调只组装上下文，不在里面提前发送真实请求。

捕获函数返回的是经过验证的条目集合；关键词扫描测试使用字面字符串，不会执行正则或模板。实际酒馆的扫描、递归、常驻、继续、重生成、群聊及其他插件宏处理路径均尚未注册/验证。只操作本插件条目，不声称解决其他插件自己的跨聊天读取问题。

## 6. 投影工作台与日常页接线

页面包括主世界书/当前范围/源版本、隔离证据、同模板的导出概览、最终正文/标题/关键词预览、实时新增/更新/删除/停用差异，以及粉色确认区。

操作明确分开：

- 检查与预览：查询，不写入。
- 仅查询同步结果：独立读回，不写入、不调用 AI。
- 去表级导出参数：导航到 T6 同一配置，缺导航时明确禁用。
- 同步：确认受控范围后执行。
- 仅重试投影：旧绑定仍有效时重试或确认，不重新生成世界。
- 修复：按当前正式版本修复漂移/孤儿。
- 逻辑重建：完整重算同一受控范围，不清空其他内容。

无目标、能力未知、旧任务过期、内容/大小/权限错误时保持预览并禁用写入。操作开始或代际变化后清除先前勾选的确认。页面卸载只取消视图订阅，不关闭共享服务；根服务关闭才撤销排队任务。新建服务、打开页面和检查不会自动同步。

T11 可以直接注入 `projection.summary` 与
`projection.subscribe`，总览的“世界已保存 / 投影待同步”独立反映当前投影。运行服务不因投影失败反向撤回已经成功的世界提交。正式入口的自动同步策略仍需结合实际宿主与已验证捕获驱动接线，本阶段不启用旧自动重试。

## 8. 真实关口与未执行事项

真实接口尚无证据证明主 AI 请求级过滤、源版本 fence、全相关写入者互斥和捕获门控。`createT12ReadOnlyDriver`
固定未验证能力，写入与捕获都失败关闭；没有实现一个伪“已验证”的 TavernHelper 生产驱动。

后续指定测试范围需验证：准确角色卡/primary/聊天绑定、持久独立读回、同步与请求捕获互斥、所有受支持生成入口、递归/常驻/关键词过滤、切卡/切聊天/并发/中断、一致代际、旧写入器退出，以及非 JSON/RegExp 外部条目的无损处理。未支持格式不可静默抹掉，不能为通过测试直接覆盖整本书。

本阶段未调用真实 API，未写实际聊天或世界书，未迁移/清空旧 IndexedDB，未导入旧生产入口，未生成共享 bundle 或新导入 JSON，未提交/推送 Git。三个既有生产文件保持原哈希。真实世界书写入与实际主 AI 触发需指定范围授权和运行证据，不能用本地测试替代。
