# 世界演变控制台 API 页面重排计划

> 计划版本：A0.1.0-alpha.13
> 计划日期：2026-09-30
> 当前基线：A0.1.0-alpha.12 发布候选
> 当前状态：UI-7 最终回归、发布候选与真机验收准备已完成，等待 SillyTavern 真机验收

## 1. 目标

将 API 配置从“自动演变”页面中拆出，放到“演变配置”分组下的独立“API 配置”页面。

目标导航：

```text
演变配置
├─ API 配置
├─ 自动演变
├─ 填表提示词
└─ 备份与迁移
```

调整后：

- “API 配置”只负责预设、Key、主备路由和工作流助手兼容桥接；
- “自动演变”只负责自动触发、手动运行、候选数量、重试和世界书同步；
- API 配置、数据库、世界书、MVU 和工作流助手数据结构不变；
- 不产生新的数据库迁移，不改变现有世界演变引擎路由；
- 不要求重新填写已经保存的 API 配置。

## 2. 当前实现基线

当前控制台存在两套 API 相关入口，重排时必须一起处理：

### 2.1 新版内置 API 页面

`src/世界演变/console/Workspace.vue` 当前在 `evolution` 页面内挂载：

```text
<ApiSettingsPanel />
<div ref="evolutionHost" />
```

`ApiSettingsPanel.vue` 负责：

- 内置 API 预设；
- Endpoint、模型、Key、超时和重试；
- 主 API 与备用 API；
- 工作流助手桥接状态；
- 本地模拟连接测试。

### 2.2 旧版运行面板 API 区域

`src/世界演变/ui.ts` 的 `mountWorldEvolutionPanel()` 内仍有旧的 API 配置区域，主要编辑：

- 工作流助手主预设名称；
- 工作流助手备用预设；
- 旧版 `apiPresetName` 和 `apiFallbackPresetNames` 设置。

这部分字段仍需保留用于兼容和迁移，但不应继续作为第二套可编辑 API 页面。

## 3. 不变的存储与运行边界

本次只调整 UI 入口，不调整以下内容：

- `world_evolution_api_config_v1` 脚本变量；
- API 配置版本和预设结构；
- API Key 脱敏规则；
- `callWorldEvolutionApiWithRouting()` 路由逻辑；
- 工作流助手 `AcuPostProcessAPI` 桥接；
- 世界演变数据库 revision、floor_run 和 checkpoint；
- `WorldEvolution-*` 世界书投影；
- MVU、工作流助手和聊天数据。

已有内置 API 配置应在页面移动后自动出现在新“API 配置”页，不能通过 UI 重排触发清空或重新迁移。

## 4. 分阶段实施

### UI-1：基线与隔离

修改内容：

- 从当前 alpha.12 发布候选建立 UI 重排分支；
- 记录 alpha.12 导入包和 alpha.11 回退包指纹；
- 确认 API 配置变量、数据库和世界书均不参与本次迁移；
- 固定一份页面截图作为重排前基线。

验收：

- 当前版本可以正常打开控制台；
- API 配置和数据库仍可读取；
- 没有产生任何真实 API 请求。

### UI-2：新增独立 API 页面路由

修改 `Workspace.vue`：

- `WorkspacePage` 增加 `api` 页面类型；
- “演变配置”分组增加“API 配置”导航项；
- 增加 API 页面图标、面包屑和页面标题；
- 增加独立的 API 页面容器。

建议页面标题：

```text
API 配置
API 预设、主备路由与工作流助手兼容设置
```

验收：

- 侧栏可以打开“API 配置”；
- 页面切换不改变数据库页、自动演变页和其他页面状态；
- API 页面可以独立滚动。

### UI-3：面板迁移验收与布局收口

UI-2 已将 `ApiSettingsPanel` 移至 `api` 页面；本阶段验收移动后的行为和页面布局：

- API 页面单独挂载 `ApiSettingsPanel`，自动演变页不再包含该表单；
- 使用 `v-show` 保持 API 面板实例，避免切页时丢失未保存表单；
- API 面板在可用宽度内居中，限制最大宽度并在窄屏切换为单列；
- 验证 API 预设增删改、Key 留空保留/显式清除/复制时不复制、主备路由、工作流助手桥接和本地模拟测试；
- 不改变 API 配置结构和预设脚本变量保存位置。

验收：

- 已有预设、Key 状态、主 API 和备用路由全部保留；
- 新建、编辑、复制、删除、显式清除 Key 和模拟连接测试仍可用；
- API 页面刷新后配置仍能读取。

### UI-4：收口旧版运行面板 API 入口

处理 `src/世界演变/ui.ts` 中的旧 API 配置区域：

- 删除或隐藏旧版可编辑 API 表单；
- 保留 `apiPresetName` 和 `apiFallbackPresetNames` 字段用于兼容旧数据；
- 保留旧设置迁移和引擎读取能力；
- 如需提示，在运行面板显示只读状态：

```text
API 配置已统一到“演变配置 → API 配置”
```

- 不保留第二套主备路由编辑逻辑；
- 不让旧面板覆盖新版 `world_evolution_api_config_v1` 配置。
- 旧版面板只显示新版有效路由摘要和跳转位置，不再编辑 API 配置；
- 手动运行/自动演变可用性根据新版有效路由及兼容桥接状态判断。

验收：

- 控制台中只存在一套可编辑 API 配置入口；
- 旧版工作流助手配置仍能作为兼容来源；
- 使用新版内置配置时，运行引擎不会被旧表单覆盖；
- 仅有旧版配置时，桥接路由仍然可用。

UI-4 完成记录见 [`WORLD-EVOLUTION-API-UI4-LEGACY-ENTRY.md`](WORLD-EVOLUTION-API-UI4-LEGACY-ENTRY.md)。

### UI-5：重排自动演变页面

自动演变页只保留运行相关内容：

- 世界演变启用开关；
- 自动触发开关；
- 手动运行；
- 候选对象和数量限制；
- 重试、队列和稳定楼层设置；
- 世界书自动同步；
- 最近运行状态和错误信息。

页面顶部增加简短的 API 状态卡：

```text
当前来源：内置 API / 工作流助手桥接 / 未配置
主模型：xxx
备用路由：x 个
Key：已配置 / 未配置
```

可提供“前往 API 配置”按钮，但不在自动演变页重新放置 API 表单。

验收：

- 自动演变页首屏能看到运行控制；
- 不需要滚过完整 API 表单才能找到自动运行设置；
- API 状态与真实路由配置一致。

UI-5 完成记录见 [`WORLD-EVOLUTION-API-UI5-AUTO-RUN.md`](WORLD-EVOLUTION-API-UI5-AUTO-RUN.md)。

### UI-6：排版与响应式优化

针对当前截图中的宽度和空白问题调整：

- API 页使用独立的页面宽度和滚动区域；
- 预设、编辑表单、路由和桥接状态使用清晰的卡片分区；
- 窄窗口时表单由多列自动切换为单列；
- 适配 100%、110%、125% 控制台缩放；
- 修正卡片内容被挤压、按钮过密和底部内容不可见的问题；
- 保持浅色、深色、奶油风和地雷色主题；
- 不改变数据库内嵌面板的宽度和滚动行为。

验收：

- API 页和自动演变页均可完整滚动；
- 不同缩放下没有横向溢出；
- 数据库、世界书投影和楼层记录页面没有样式回归。

UI-6 完成记录见 [`WORLD-EVOLUTION-API-UI6-RESPONSIVE.md`](WORLD-EVOLUTION-API-UI6-RESPONSIVE.md)。

### UI-7：测试、构建与发布候选

自动化检查：

- API 配置读写与脱敏测试；
- API 路由测试；
- 世界演变 AI 调用测试；
- 数据库 revision、重建和投影测试；
- ESLint；
- 生产构建；
- alpha.11 文件指纹检查。

页面验收：

- 导入后默认关闭；
- API 页面可以打开；
- 模拟连接测试不访问网络；
- 页面切换不丢失配置；
- 自动演变页不再出现重复 API 表单；
- 停用新版后可以回退 alpha.11。

发布候选版本：

```text
A0.1.0-alpha.13
```

该版本代表 UI 重排的独立发布候选，不增加数据库版本，也不改变 API 配置 schema。运行时数据库版本仍为 `A0.1.0-alpha.11`；A0.1.0-alpha.12 和 alpha.11 导入包继续保留作为回退版本。

UI-7 自动化回归结果与真机验收清单见 [`WORLD-EVOLUTION-API-UI7-RELEASE-CANDIDATE.md`](WORLD-EVOLUTION-API-UI7-RELEASE-CANDIDATE.md)。

## 5. 测试矩阵

| 场景 | 预期结果 |
| --- | --- |
| 已有内置 API 配置 | 新 API 页面正常显示，不要求重新填写 |
| 只有旧工作流助手配置 | API 页面显示桥接状态，运行仍可兼容 |
| 内置 API 与桥接同时存在 | 页面只显示一套编辑入口，路由优先级不变 |
| 页面切换 | API 表单和运行设置不被清空 |
| 自动演变页 | 只显示运行控制和 API 状态摘要 |
| 模拟连接测试 | 使用本地模拟响应，不访问网络 |
| 数据库和世界书页面 | 样式和功能不回归 |
| alpha.11 回退 | 旧页面和旧配置仍可使用 |

## 6. 明确不做的事情

- 不修改数据库 schema；
- 不修改 API Key 存储方式；
- 不删除旧版兼容字段；
- 不删除工作流助手；
- 不改变世界演变引擎的路由优先级；
- 不在本阶段开启自动世界演变；
- 不进行未经确认的真实 API 调用；
- 不清空聊天、楼层、IndexedDB 或角色卡世界书。

## 7. 完成标准

满足以下条件后，才认为 UI 重排版本可以交给真机验收：

- API 配置成为“演变配置”下的独立页面；
- 自动演变页面不再包含重复 API 表单；
- 新旧 API 配置兼容逻辑仍然有效；
- API 配置、数据库和世界书数据均未丢失；
- 页面在常用缩放和窄窗口下可用；
- 模拟测试、受影响目录 ESLint 和生产构建通过；全仓库既有 ESLint 错误不属于本阶段改动；
- 新测试包默认关闭并带明确版本号；
- alpha.11 仍可作为回退版本。
