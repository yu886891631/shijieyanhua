日期：2026-10-10。

对应用户请求：“开始第 1 项。仍不调用收费 API、不动实际聊天，也不覆盖当前测试包”，以及后续“继续”。本项仅补数据库整轮完成通知和世界演变消费适配，不进入第 2 项自动触发、所有权与去重接线。

## 1. 当前结果

完成代码和一份独立源码兼容补丁；补丁已通过固定参考版本的只读应用检查，但没有实际应用、安装或构建第三方数据库。没有改变世界演变现有导入包、生产 bundle 或隔离候选 bundle。

现在代码能区分：本轮所有计划组成功、失败、取消、明确停用、按频率无任务，以及无法验证。普通“表格有变化”和某个批次完成仍不能当整轮完成。成功通知只提供候选；独立读取聊天存档确认来源字段保存之后，才可能释放世界演变前置关口。

这不等于用户当前页面已经获得该能力，也不等于真实游戏运行版完成。补丁未安装或版本不支持时，必要数据库来源继续等待/阻断。

## 3. 代码与交付文件

- `t15-db-completion-protocol.ts`：可移植来源协议，捕获目标、不可复制 ticket、计划、组回执、终态和分离的 JSON 快照；没有网络/存储/UI 副作用。
- `t15-db-completion-adapter.ts`：世界演变消费端，只接受已观察 begin 的本轮终态；匹配消息对象、角色/聊天、swipe、正文和消费端事件 epoch。
- `t15-db-completion-patch.ts`：Node 开发工具，只读参考源并输出补丁；检查原文件精确哈希和唯一锚点，不修改参考 checkout。
- `compat/shujuku-round-completion/automatic-plan-v1.patch`：固定版本四文件补丁；不是导入 JSON。
- `t15-source-signals.ts`：检测明确协议接口，连接观察/清理及数据库候选应用；版本缺失或不匹配不回退到普通更新通知放行。
- `t15-native-workspace.ts`：应用数据库候选，真实发送授权时再次核对当前性；新的数据库作业或静默数据变化也会阻断旧授权。
- `t15-host-build-smoke.mts`：额外单独编译原生来源观察工厂，避免工作台的注入类型让这部分漏出构建检查。

开发者使用边界见 [兼容补丁说明](../compat/shujuku-round-completion/README.md)。

## 4. 候选有效性与保存确认

1. 来源提供版本明确的只读观察接口：`WorldEvolution/TavernDB-auto-round/1`、`coverage: ['automatic-plan']`、`candidateOnly: true`。消费端不能调用生产者 begin/finish。
2. 目标必须是当前已加载单角色卡聊天的有效最新 assistant 消息。消息对象、swipe、正文和当前隔离标签一起捕获；不拿楼层号或正文相同冒充消息身份。
3. 每个计划组只登记一次。未知/缺失/重复组、失败组、结构错误或最终汇总矛盾都不能成功；停止及 coalesced 后续作业撤销本次成功资格。
4. 终态捕获本轮隔离标签的 `TavernDB_ACU_IsolatedData`
   V2 数据，以及用于当前性检查的运行时导出。跨 iframe 普通 JSON 数据可复制；大小、深度、节点数及危险字段有硬限制。
5. 消费端只允许当前隔离标签对应的来源字段，不能读取另一隔离库、任意缓存或样例值。变化发生于在途流程时，普通更新提示维持等待但不丢失本轮 begin；终态之后的数据变化则撤销候选。
6. 候选应用后，既有前置关口仍独立读取服务端 JSONL，核对稳定身份、剧情、事件版本和所选来源字段。数据库声称 `persisted`
   或完成通知本身都不能跳过读回。
7. 没有观察 begin、已刷新重载、当前数据库忙碌或运行时数据变化时，不回放旧成功。取消监听/pagehide 清理；观察器异常不能改变第三方数据库原流程。

来源端 epoch 固定为本实例范围；原生消费端另外使用酒馆输入事件 epoch，并在发送边界再次检查当前来源。该设计仍是单活动页面兼容方式，没有服务端 CAS、跨标签页锁或跨全部插件原子保证。

## 5. 最终验证

最新代码的定向回归一次运行 **98/98 通过**：

- 数据库协议/消费适配：23 项。
- 实际补丁源接线：11 项。
- 既有 T15 接线：13 项。
- 既有宿主读取：29 项。
- 既有 API transport：22 项。

补丁源测试在内存中编译并运行生成的 API registry、外层 automatic trigger、native glue 和 portable
protocol，注入假宿主/执行器/保存/模型服务。验证 grouped + staging、legacy SQLite +
staging、全部组已结束但外层仍未收口、汇总成功掩盖失败/缺组、停止、异常、前置失败、明确停用、无表到期、coalesced 后续，以及后续 busy 阻止候选复用。

这比单独协议测试多覆盖了真实补丁插入点，但仍不等于完整第三方服务实现、第三方生产构建或用户实际页面验收。测试中保存、世界书与模型均为替身，不调用收费服务或实际聊天。
