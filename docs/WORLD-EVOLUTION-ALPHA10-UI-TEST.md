# 世界演变 A0.1.0-alpha.10 UI 测试说明

> 日期：2026-09-28
> 状态：测试包已推送；等待 SillyTavern 真机 UI 验收

## 本版改动

- 将旧的浮动面板整理为居中工作台，提供总览、世界资料、楼层记录、世界书投影、自动演变、填表提示词、备份迁移、外观与显示八个页面。
- 自动演变页面聚焦于触发、数量限制、重试与手动运行设置；对象表、楼层记录和投影管理分别放到自己的页面。
- 提供主题/缩放设置和多消息提示词草稿编辑器。提示词草稿不参与真实生成流程。
- alpha.10 使用独立脚本 ID 和新的缓存参数；数据库分区与 alpha.9 相同，会继续读取和写入当前聊天已有的 IndexedDB，不是数据沙盒。

## 导入与验收

1. 导入 `导入到酒馆中/酒馆助手脚本-世界演变控制台-A0.1.0-alpha.10-测试版.json`，先保持关闭。
2. 禁用 alpha.9 测试包；如果 alpha.8 的「世界演变」或「世界演变数据库」脚本仍启用，也一并禁用。保留脚本，不要删除。
3. 启用 alpha.10，打开「世界演变控制台」，检查八个页面是否都能切换、内容是否在中央工作台内显示。
4. 查看世界资料表、楼层记录、世界书投影和备份迁移页面；确认主题与缩放可以切换。
5. 查看「填表提示词」页面，确认编辑、排序、保存草稿、JSON 导入/导出正常。
6. 本轮仅验收 UI。不要打开自动演变，不要点击「手动运行一轮」，不要启用自动触发，避免真实 API 消耗。

## 数据与回退

- alpha.10 不会清理、迁移或重建聊天数据；它会连接 alpha.9 使用的同一数据库。
- 如需回退，先关闭 alpha.10，再重新启用 alpha.9。不要同时启用两个版本，也不要清空数据库。
- 真机验收完成前，不覆盖稳定导入入口，也不把草稿提示词接到生成流程。
