# 世界演变 A0.1.0-alpha.11 API 路由测试说明

> 状态：本地实现与模拟测试通过；尚未上传 GitHub，尚未进行 SillyTavern 真机检查，也未调用真实 API。

## 本版内容

- 世界演变生成通过工作流助手暴露的安全桥接调用，不读取或保存 API Key，也不回退到酒馆当前全局 API。
- 自动演变页可跟随当前聊天的 API 预设，或指定主预设，并勾选、调整备用路由顺序。
- 兼容工作流助手旧版仅有顶层 API 配置、没有命名预设的情况。
- UI 只收到模型、端点是否已配置、Key 是否已配置；不暴露原始端点 URL。
- 插件默认关闭；本版继续连接 alpha.10 使用的聊天数据库，不会重置或清理它。

## 真机检查

1. 先在酒馆启用工作流助手，并在其 API 页面保存至少一个可用配置。
2. 导入并保持关闭 `酒馆助手脚本-世界演变控制台-A0.1.0-alpha.11-API测试版.json`。
3. 停用 alpha.10 和更早的世界演变脚本后，再启用 alpha.11，避免两个版本同时运行；保留旧脚本以便回退，不删除或清理世界演变数据库。
4. 打开控制台的「自动演变」，点击「刷新预设列表」，检查主 API、模型状态、Key 状态和备用路由是否显示正确。
5. 改选主预设、设置备用顺序，点「保存设置」，关闭后重新打开确认仍在。
6. 这一步只验配置 UI：保持「插件启用」与「自动触发」关闭，不点击「手动运行一轮」或「重试」，不要发送测试楼层。以上操作会实际调用 API。

本地版的导入 JSON 在源码进入 GitHub 并由自动 bundle 工作流生成 `dist` 后，还需把两个 import 地址固定到新的 bundle 提交，届时再导入真机验收。
