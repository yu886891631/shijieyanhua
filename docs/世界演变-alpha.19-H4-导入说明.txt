世界演变 alpha.19-H4：直接打开工作台

这次主要修正“点开后先出现一大页连接/验收选项”的问题。
现在打开就是完整控制台，自己识别你当前打开的单角色聊天。

怎么换：
1. 保留聊天备份。不要同时启用两个世界演变脚本。
2. 最省事的方式：在现有世界演变脚本里，把“脚本内容”换成给你的新 import 一行。
   只替换内容可以保留原脚本 ID，对应的本地 API 设置也不用另搬。
3. 也可以导入“酒馆助手脚本-世界演变-A0.1.0-alpha.19-H4-直接打开工作台测试版.json”。
   新导入包有不同 ID，所以旧脚本的 API 设置不会自动复制过来；它默认关闭，需要你启用。
4. 刷新酒馆，点击“打开世界演变面板”，确认顶部显示 A0.1.0-alpha.19-H4。
   不需要为了这次入口调整重新换正则。

打开后能做什么：
总览：看当前聊天和准备情况。
世界资料：查看宏观、微观表。还没有存档时，会显示七张空白默认表，不会塞入演示角色。
API 配置：可直接填写，不用先创建世界资料。
其他页面：楼层记录、世界书投影、自动演变、填表提示词、备份与迁移、外观与显示。

哪些动作会保存：
仅打开、查看、刷新资料，不会创建聊天存档或调用模型。
首次在世界资料里点“创建并保存空白默认表”，只会询问一次是否保存到当前聊天。
点取消就不保存。确认后才建立本插件的空表存档，然后可以新增 NPC、修改资料等。
后续“保存到当前聊天”保存的是真实聊天中的世界资料，不是独立沙盒。
不会因此修改剧情正文、调用模型或自动写世界书。

哪些动作可能收费：
填写 API、保存 API 设置，不等于发起世界演变。
“模拟连接测试”只是本地模拟，不证明你填的真实接口能用。
手动演变和开启后的后续自动演变会使用配置好的真实 API，可能收费，需要另外明确启用。
世界书同步是另一项操作，打开页面不会自动同步。

如果提示“数据库完成接口尚未接入”：
不是要你连接一个外部服务器。
意思是：世界演变还没有收到数据库这一轮“确实处理完了”的可靠通知。
这个状态可以看表、编辑表、配置 API，但不能直接启动演变。
本次更新解决入口不好用的问题，没有偷偷跳过这个等待检查。

当前仍是测试版：
本地模拟和回归检查已经进行，但还没有在你的真实酒馆完成整条流程的验收。
不要直接当正式自动运行版使用。后续先在备份好的测试聊天中受控验证。
没有自动迁移你的旧资料，也没有覆盖旧发行包。

收起与刷新：
收起保留当前打开实例和草稿，不自动保存，也不取消后台请求。
刷新页面、重载脚本或卸载实例可能丢失未保存草稿；先保存或取消再刷新。
