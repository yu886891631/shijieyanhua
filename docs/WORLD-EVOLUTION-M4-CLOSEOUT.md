# 世界演变 M4 收口记录

> 版本：A0.1.0-alpha.4
> 日期：2026-09-26
> 状态：本地模拟验证完成，SillyTavern 真机未验收

## 已完成

- AI prompt、JSON schema 与解析入口统一改为 `{"baseRevision":number,"operations":[...]}`；
- 只接受实体 `upsert`、受保护实体 `delete`、事件/计划 `append` 和 `update_status`；
- 校验候选姓名与本库稳定 ID、外部表 ID 隔离、字段白名单、引用目标及类型、文本大小、
  总操作数、实体和事件/计划限额、重复 ID、已知资料保护和可见性转换；
- 所有操作先校验再转换，失败不执行数据库提交，也不更新世界书；
- 真实写事务内重新读取 revision 做 CAS，跨脚本实例的旧 `baseRevision` 不能覆盖新提交；
- 成功批次仍生成 revision、逆向操作和 floor_run，复用 M2 确定性回放；
- 旧版 `updates/events/scheduledEvents` 响应不兼容，失败时显示校验错误；
- 删除保护按整批操作的最终引用状态检查；同批次先解除引用、再删除 backstage 实体时可安全提交。

  重复 ID、错误引用和引用类型、限额、可见性、删除保护、状态转换、
  后置非法项整批拒绝和两层 `baseRevision` 冲突；
- 世界演变数据库与世界演变相关模拟测试：31/31 通过；生产构建成功；

  M4 涉及文件没有新增类型诊断。
