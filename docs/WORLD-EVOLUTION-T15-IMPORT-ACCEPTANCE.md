# H3：导入入口接入与受控真机验收准备

日期：2026-10-10。候选：`A0.1.0-alpha.18-H3`。

## 1. 交付范围

按用户请求接入导入入口，沿用九页 UI，准备受控实际酒馆验收。生成新的自包含 JSON 和版本目录，不覆盖正式 bundle、alpha.16 或固定 alpha.17-T15.1。初次生成时仅存本地；用户随后明确要求提交并推送 GitHub，分发方式见第 6 节。没有安装数据库补丁或操作用户实际页面。

这是可真实读写的候选，不是隔离沙盒，也不是已验收正式版。第一轮真机验收只安排入口和只读检查；真实聊天保存、收费请求、主世界书写入和恢复各须明确确认。

## 2. 接线

- `t15-import-entry.ts`
  安装独立菜单/按钮与固定 srcdoc。重复入口不取得或删除别人的菜单，卸载主动注销 App。收起只隐藏并保留会话，不取消远端请求。
- 原酒馆助手 iframe 以明确 API getter 列表向新面板提供原脚本 ID/上下文。没有通用代理或 JSON 恢复授权；MVU
  getter 保持动态。未点击检查前，不读聊天、不读 Key、不连接来源或工厂。
- `t15-import-native.ts`
  只读核对脚本清单、已存在单角色聊天、当前助手回复、已保存新格式状态、MVU 就绪、数据库协议/实际隔离组及角色卡主世界书。目标事件监听保留到断开/重查，A→B→A 也不能恢复旧检查票据。
- `t15-import-runtime.ts` 先观察再显式连接，冻结来源映射。默认 MVU
  `stat_data`，数据库只接受当前已保存隔离组；候选过大由原有上下文限制阻断。必要数据库缺协议不采用通知/延迟兜底，不默认关闭该来源。
- 连接可以初始化空白新格式，但须独立勾选；非空存档按原恢复流程处理。连接只允许保存，真实 API/自动运行仍关闭；不迁移旧库或种演示角色。
- 新九页会话交给原 H2 生命周期，支持显式初始手动会话接管。API 表单草稿加入交接保护；以后每个会话也保留这个保护，不止首次。
- API 仍使用当前新脚本 ID 的配置层，不静默复制旧 Key。模板路由、整轮预算、来源证明、去重、保存恢复和世界书使用已有控制器。自动开启须额外明确授权；打开、刷新或勾选本身不请求模型。

## 3. iframe JSON 边界

实际宿主/MVU/数据库数据可能来自另一 iframe，其 plain
Object/Array 原型并非本窗口的原型。新增边界限定复制器，在 getter/toJSON 不执行、类实例/访问器/循环/符号/不安全键/多余数组字段拒绝的条件下复制为本窗口纯 JSON。T2 内部严格克隆规则没有放宽。

用于 MVU 完成资料、数据库协议 coverage/绑定/终态数据、写前宿主 metadata/messages 比较、精确自有世界书通知，以及只读世界书 entries。原消息/变量/ticket 对象仍保持能力身份，不能深拷贝后当有效票据。

用户先导入并启用新候选，停用旧世界演变写入脚本，保留原 MVU/填表数据库；打开备份测试聊天，只点只读检查。

`599e3580c3106fa234ead38fdfe8625080419143`，未安装，不能盲目给其他版本打补丁。未完成这个关口，不把必要数据库关闭来宣称全链成功。
