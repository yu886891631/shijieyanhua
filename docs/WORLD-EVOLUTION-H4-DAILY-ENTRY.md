# H4：直接打开完整工作台

版本：`A0.1.0-alpha.19-H4`。本次是入口和宿主呈现调整，不重做表格、SQL、事务或世界书投影内核。

## 用户看到的变化

- 点“打开世界演变面板”直接显示原九页控制台，自动只读识别当前单角色聊天。不再先显示 H3 的连接/验收向导。
- 新聊天显示空白的宏观、微观默认表：社会、环境、地点、NPC、组织、计划、事件。此时尚未保存，不填入演示角色。
- API 页面不要求先创建聊天存档；查看已有资料不要求先接入数据库完成接口。
- 创建空白存档、或为尚未注册当前楼层的既有存档启用编辑时，只在资料页进行一次具体的保存确认。取消不会初始化存档。
- 已有健康且当前消息已注册的存档可直接挂载原控制器；打开时不重新注册消息、不保存聊天。
- 表格编辑、结构迁移、手动运行的真实聊天文案与原隔离模拟文案分开；提示词页真正的本地模拟预览仍保留模拟标识。
- 收起保留当前实例；不自动保存草稿、不取消后台请求。刷新或卸载仍可能丢失未保存草稿。

## 权限和触发边界

打开入口只安装菜单；打开控制台只读取聊天、角色卡主世界书绑定及接口准备情况。不自动初始化、注册楼层、迁移旧数据、授予真实 API 权限或同步世界书。

资料页明确确认后，空聊天才建立本插件自己的表格存档及消息身份；后续“保存到当前聊天”会写真实当前聊天，不是沙盒。所有写入仍由既有统一事务网关执行。

真实 API、后续自动演变、世界书同步均默认关闭并保留明确操作边界。配置 API 不等于启动演变；连接测试仍是本地假响应，不证明真实模型可用。

自动触发仍由 H2 生命周期与触发所有权模块处理；不在只读刷新中重建正在使用的同轮观察器。切聊天、旧草稿、未确认结果、停止信号仍使用原失效/去重保护。停止自动的动作不会被草稿检查挡住。

数据库只有一个实际隔离表组时自动选择；多个时从实际列表中选择，不猜示例键。检测到数据库却缺少完成协议、没有确认实际表组，或必要 MVU 尚未就绪时，阻止运行，不阻止资料浏览/编辑。不用延时定时器冒充完成信号。

## 导入与兼容

输出是新的固定版本目录 `dist/世界演变候选版/A0.1.0-alpha.19-H4/`
和独立脚本 JSON，不覆盖旧 H3、alpha.17、alpha.16 或主 dist。

优先在原有世界演变脚本里仅替换 import 内容，保持原脚本 ID 与本地 API 设置。新 JSON 使用不同脚本 ID；直接新导入时不会自动复制另一脚本 ID 的 API 设置。不要同时启用旧世界演变写入脚本和 H4。刷新后再打开，确认页头为 alpha.19-H4。

## 尚未完成的验收

本版不宣称正式发布。尚未在用户的实际酒馆完成“真实生成 →
MVU/数据库结束 → 宏观 → 微观 → 保存 → 主世界书”的端到端验收；未调用收费 API、未写用户聊天、未改用户数据库脚本。

数据库完成协议补丁没有因本次入口调整自动安装。如果页面提示接口缺失，运行仍须完成对应接线后再验收。宿主仍是单活动页面的乐观并发保护，不是服务端 CAS；不要多个页面或多个插件同时写同一聊天。
