# 世界演变控制台 UI-4 收口旧版运行面板 API 入口

> 完成日期：2026-10-01
> UI 计划版本：A0.1.0-alpha.12-ui.1
> 基线提交：`e873b73`
> 状态：UI-4 已完成，下一阶段为 UI-5 重排自动演变页面

## 1. 本阶段目标

取消旧运行面板中第二套工作流助手主/备 API 路由编辑入口，避免旧的 `apiPresetName` / `apiFallbackPresetNames` 选择与新版 API 页面设置分叉。

## 2. 已完成修改

修改文件：

```text
src/世界演变/ui.ts
```

- 删除旧版主 API 预设下拉菜单、备用路由勾选框和顺序调整按钮；
- 替换为只读“API 路由状态”卡片，说明唯一编辑入口为“演变配置 → API 配置”；
- 保留手动刷新路由状态按钮；
- 状态摘要通过 `loadWorldEvolutionApiConfiguration()` 和纯路由解析读取新版有效来源，不读取或显示密钥；
- 路由状态按实际调用顺序判定：桥接和内置 API 都不能把“失效主预设后的有效备用项”误报为可运行；被禁用的内置主预设会按引擎行为跳过；内置 Key 采用去空白检查；
- 手动运行和自动触发控制使用新版内置路由 / 工作流助手桥接的可用状态，不再只检查旧版工作流助手预设信息；
- 运行设置保存时不再归一化或改写旧主/备预设名称。

## 3. 兼容边界

未修改以下内容：

- `WorldEvolutionSettings` 类型中的旧版主/备字段；
- `store.ts` 中旧设置读取、默认值和保存兼容；
- `engine.ts` 向 API 配置读取函数传递旧版配置的兼容行为；
- `api-config.ts` 的新配置优先、旧字段作为缺失时回退迁移的逻辑；
- API 配置脚本变量、路由策略、Key 存储、工作流助手桥接实现。

新版配置存在时，旧面板不再写入旧路由字段；新配置缺失时，旧字段仍可由原读取/迁移路径识别。未执行实际迁移、API 调用或聊天数据操作。
