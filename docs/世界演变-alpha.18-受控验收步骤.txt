世界演变 alpha.18-H3：先检查，再分步试用
日期：2026-10-10

这是新流程的“真实接线候选包”，不是已经验收的正式版。
它和 alpha.17 的隔离内存测试包不同：连接后，世界资料的保存会写当前聊天。
代码内嵌在 JSON 中，不需要先推送 GitHub，也不用另外填写 import 链接或导入正则。
不要拿目前旧链接下载到的版本代替这个新包。
GitHub 分发位置是 codex/world-evolution-alpha14-u9 测试分支中的同名新 JSON。
main 分支及原 @main 链接仍保留旧版；下载时请认准 alpha.18-H3。

一、你现在只需要做这些（第一轮不收费、不写聊天）

1. 保留旧文件，只停用旧“世界演变/世界演化”脚本，包括旧测试版。
   不要停用角色卡原有的 MVU 或你正在使用的填表数据库。
2. 备份聊天，准备一个专门的单角色测试聊天。只保留一个活动的酒馆页面。
   测试聊天最后一条应是已经保存的助手剧情，不是用户消息。
3. 导入：酒馆助手脚本-世界演变-A0.1.0-alpha.18-H3-真实接线候选版.json
   包默认停用；你手动启用后，菜单/脚本按钮应出现 alpha.18-H3。
4. 打开“世界演变 · alpha.18-H3 · 真实接线候选”。
5. 只点“1. 只读检查当前聊天”。
   暂时不要勾保存授权，不点“连接测试工作台”，不允许真实 API 或自动运行。
6. 把检查结果截图给我，或者打开页面让我查看。

这一轮只核对：菜单、窗口、版本、当前角色/聊天、存档状态、主世界书、MVU 是否就绪、数据库完成接口和实际隔离组。
只读检查会向本地酒馆读取已经保存的聊天，不发给模型，不保存聊天、不写世界书。
缺主世界书时不创建也不改绑；旧脚本冲突时不会替你关闭其他脚本。

二、看到数据库“未检测到整轮协议”，不是你配错 API

原数据库的“表格更新”通知不代表本轮所有组都完成。
本项目已准备固定参考版本的源码兼容补丁，但还没有安装到你的数据库脚本中。
选了“等待数据库”而该接口缺失时，会阻止演变请求；这是保护，不应通过取消必要来源来绕过。
我们先核对你实际安装的数据库版本，再由我准备对应的安装方式。
你不需要自己改源码。此新包没有偷偷替换或修补你的数据库。

三、之后由我带你分开验收，不需要现在一口气点完

A. 测试聊天保存：你明确同意后再连接。
   没有新格式存档时，另行勾选“初始化空白默认表”。
   只保存世界演变自有存档和消息身份，不迁移旧库，不修改剧情正文，不填示例角色。
   世界资料、结构参数、采用 API 主预设等保存按钮可能写这个测试聊天。
   保存一条测试资料，刷新后只读复核。出现失败/不明结果时不反复点保存。

B. 来源等待：先开始观察，再产生新剧情。
   旧通知不会回放。MVU、数据库确实都完成且结果读回一致后才允许演变。
   实际不用某插件的聊天才可取消该前置。默认 MVU 读取 stat_data，数据库使用本聊天实际选择的隔离组。
   新格式会话的角色卡主世界书只作为投影目标；没有自动抓取全部世界书作为模型上下文。

C. 收费 API：需要再单独约定请求上限与使用的预设。
   新脚本 ID 和旧版不同，不会自动复制旧 Key；API 页需重新配置或按页面支持的方法导入。
   “模拟连接测试”只检查本地假响应，不说明真实服务可用。
   手动整轮运行、同轮续跑和已明确启用的自动演变可能产生真实费用。
   初次实测应关闭自动、客户端重试和备用路由，限制处理表/对象和整轮请求数。
   具体额度由你确认；界面默认值不是已同意的测试额度。
   取消/关页面不能证明服务商没计算、没收费或没保存。

D. 世界书：另行确认测试角色卡的主世界书后，再预览和同步。
   同步是真实写入。只管理本插件有归属标记的条目，不应改动 MVU、TavernDB 或用户的其他条目。
   同步后核对内容、重复同步、孤儿清理及主 AI 的实际调用。此部分尚未真机验收。

E. 恢复与自动：确认保存/预算/投影后，再测试删楼、swipe、重载和自动接管。
   自动和手动共享同轮去重；失败不自动重发。
   有 API 草稿、资料草稿、暂停或保存不明时，不丢弃页面、不强行接下一轮。
   换聊天、停止生成、改 API 后需要重新授权。
   未启用自动接管而又产生新剧情时，旧会话可能过期；处理完草稿后断开、重新连接。

四、范围与回退

本包最初只在本地生成，随后按你的要求安排提交并推送 GitHub 测试分支。
上传文件不会自动安装到酒馆，也不代表实际功能已经验收通过。
没有调用收费 API，没有读写你的实际聊天或世界书，数据库兼容补丁仍未安装。
旧生产 bundle、alpha.16 包、固定 alpha.17 隔离包保持不变。
不支持群聊，也不是跨标签页/设备/其他插件的原子锁。
新格式存档目前有严格体积、提交数与数据限制；长期实际游戏能力尚未验收，不直接用于重要长存档。
停用新候选不会自动删除已经保存的世界演变字段或世界书条目。
回退前先备份；不和旧写入脚本同时启用。需要恢复备份时由你明确确认。
