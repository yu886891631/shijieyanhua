# 世界演变数据库 M2 收口记录

> 版本：A0.1.0-alpha.2  
> 收口日期：2026-09-26  
> 范围：楼层账本、revision 事务、checkpoint 与确定性回放

## 本阶段已完成

- 世界演变 AI 结果会先转换为 `WorldEvolutionDbOperation[]`。
- 真实结果统一通过 `commitDbRevision()` 写入数据库事务。
- 数据库按聊天隔离保存业务表、`floor_run`、`evolution_revision` 和 `evolution_checkpoint`。
- 同楼层相同正文使用指纹幂等处理。
- 删除楼层和滑动楼层通过统一调度器处理：
  - 同一聊天单并发；
  - trailing debounce；
  - generation 代次；
  - 旧异步结果不得提交。
- 删除或滑动历史楼层时只回放已保存 operations，不重新调用 AI。
- 受影响的 revision 与 floor run 会标记为 `stale`。
- 数据库面板提供：
  - 逻辑表查看与编辑；
  - revision / floor run 查看；
  - checkpoint 创建；
  - 手动确定性重建；
  - 数据库导入、导出和按聊天清空。

## 面板统一结果

旧版“世界演变”面板已经切换到新数据库适配层：

- 对象、事件、计划、revision、checkpoint 和楼层记录均从 `acu-world-evolution-db` 读取；
- 手动编辑、删除、checkpoint、回滚、导入和导出均写入新数据库；
- 手动操作产生新的 `manual` revision；
- 世界书同步状态也保存在新数据库的 `world_meta` 中。

旧 `acu-world-evolution` 数据库和 `src/世界演变/store.ts` 仍保留，但当前只承担设置读取、旧备份兼容和后续迁移准备，不再是运行时世界状态的事实源。旧数据迁移尚未执行；导入按钮遇到旧版备份会拒绝导入，不会清空或覆盖新数据库。
