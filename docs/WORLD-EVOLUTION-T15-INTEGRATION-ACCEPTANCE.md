# T15：统一接线、全链验收与候选导入包

日期：2026-10-09。候选身份：`A0.1.0-alpha.17-T15.1`。

## 结论与实际范围

T15 的**隔离工作区接线与本地验收候选**已经实现。T15 的正式宿主接线/真机验收尚未完成，不能把此包当成自动演变的正式游戏版本。

原 T0/T10/T12 的宿主限制没有被撤销：目前没有经过验证的独立酒馆落盘读取、保护整个聊天文档的原子比较提交、角色卡主世界书受控写入/主 AI 捕获边界，也没有真实剧情与 MVU/数据库本轮完成证明的统一入口。T7–T9 新流程目前仍是注入假响应的请求方式，而非已接入真实模型的运行入口。

本次没有用普通变量 setter 的 Promise 完成、进程内锁或用户 JSON 中的标志冒充这些能力；也没有启动收费请求、写真实聊天或写角色卡世界书。

### 本次集成修复

- 权限检查不再通过计算另一页面完整 view 间接循环；用无副作用 busy accessor 查询。
- 演算冻结允许同一轮自身运行状态；仍阻止其他草稿与过期输入。
- 历史恢复的自身提交由 T11/T4 核对归属，不被“有任意提交草稿”误判为另一轮编辑。
- 确认的外部提交可刷新数据/结构页面；未保存的结构草稿不会被静默丢弃。
- 空目标表增加仅有零条授权记录/零个字段的身份查询许可，使无变化 SQL 可校验；没有增加未发送行或字段的读取权。
- 既有 API 页面可注入内存配置；注入时不初始化旧设置、不探查 parent 工作流助手；提示文案区分本机设置与本次内存。
- 自动酒馆事件入口在此候选中明确禁用，而不是显示开关却没有事件来源。
- 自动事件能力的默认值保持既有组件行为，仅候选显式禁用；补充缺省/禁用两种页面回归，防止 Vue 布尔 prop 缺省转换影响旧页面。

## 保存与文件恢复

保存成功是当前隔离 T4 内存账本的 CAS 和读回确认，不是酒馆服务器落盘。关闭/重载前需导出完整工作区。

工作区格式 `world-evolution-t15-local-workspace / v1` 保存：一个隔离世界的 JSON 账本、结构、独立默认模板、剧情输入、已保存提示词草稿/启用版本及外观。它不包含 API 配置/Key、未保存填写草稿、正在执行的私有阶段或模拟世界书。恢复后不会续发请求；世界书预览重新计算，模拟同步需再次明确操作。

文件先核对大小、严格字段、版本、SHA-256 指纹、sandbox 身份、单世界范围、全部提交链及提示词/默认模板，再建立新工作区。失败保持原工作区。指纹用于检查损坏，不是文件来源认证或安全签名。此候选不读取/迁移用户实际旧 IndexedDB。

“保存草稿”和“启用规则”均在当前实例内存；只有工作区文件下载并在磁盘保存后才跨重载保留。普通 T13 世界备份与 T15 完整工作区文件是两种格式，不能混用。

## 候选包与构建

- 一个酒馆助手脚本 JSON；新脚本 ID；默认禁用。魔法棒菜单和脚本按钮打开同一个工作区。
- 单一 IIFE bundle 自包含 Vue、SQL Worker 与固定 sql.js 1.14.2/WASM；没有远程 import、CDN 缺文件补载或费用请求。
- 外层入口只注册 UI；内部独立 iframe 隔离酒馆样式。收起保留当前内存；脚本卸载清理菜单、按钮监听、面板与控制器。
- 重复加载同一入口通过独立标记去重；旧 alpha.16 的入口和数据不由此候选接管。
- 输出目录为 `dist/世界演变候选版/A0.1.0-alpha.17-T15.1/`，包含 bundle、独立预览与 manifest。manifest 记录实际 bundle、Worker 和源输入指纹。
- 没有生成声称已上传的新 CDN 地址；本地导入 JSON 内嵌固定 bundle。不提交 Git、不推送 GitHub。
- 原 alpha.16 生产 bundle 与旧导入包保留，并核对原 SHA-256。

重建命令（仓库根目录）：

```text
node --import tsx src/世界演变/rebuild/t15-build.mts
node --import tsx src/世界演变/rebuild/t15-build.mts --serve
```

`--serve` 仅显式启动 loopback 服务；控制台输出当次实际地址。`/` 检查真实候选 App，`/entry` 用明确标注的假宿主验证同一个导入脚本的菜单、iframe、重复加载与卸载。假宿主没有真实酒馆接口，不能代替酒馆导入兼容性验收。

## 验收证据

本地集成新增 11 项：空世界/零副作用、填写/DIY/提示词/文件重开、模拟路由不扩额、宏观→微观/一次提交/投影/账本恢复、回执丢失、损坏/错误身份/多聊天导入、Key 隔离、取消/迟到结果、非默认表完整链、非法 SQL 整轮回滚、备份/历史恢复后各页一致。

另有 2 项候选 Vue 严格虚拟 TS/模板编译与九页/入口静态边界检查。完整运行 T0–T15、旧引擎与数据库测试：**1050/1050 通过**，并发度 2，耗时约 422.9 秒。此前整套发现的自动事件能力缺省值兼容问题已修正，再跑整套通过。最后仅补齐外观 prop 默认值以消除 lint 警告，相关 T14/T15 严格 UI 回归 **8/8 通过**。

本次变更文件 ESLint 零错误/零警告；候选 Vue 严格 TS、模板与样式编译通过。构建两次得到相同 bundle 指纹。JSON 类型为 script、默认禁用、新 UUID；内嵌 content 与候选 index.js 逐字一致，manifest 的体积与 SHA-256 匹配。最终 bundle：2,375,649 字节，SHA-256 `6c90b5568d9e7f6826a1bcb06e0cf11cdd0f13eee9c48b976d65f0ac8481a761`。旧生产两份 bundle 与 alpha.16 导入包的 SHA-256 均与基线一致。

浏览器使用 computer-use 技能，仅在 loopback 假宿主/候选页使用虚构资料。实际执行新增 NPC、内嵌 Worker 校验、确认保存、楼层提交查询及源版本投影预览；没有打开或修改用户真实聊天。重复加载后确认菜单/面板/iframe 各一个；收起重开保留已保存 NPC 与版本；卸载后菜单、脚本按钮和工作区消失。截图见 `docs/t15-acceptance/isolated-ledger-confirmed.jpg`。浏览器实际验收包早于最后的外观默认值补齐，最终包的该差异由上述 8 项编译/UI 回归验证，没有把它说成重新完成过宿主实页验收。

浏览器点击导出后出现“已请求下载”提示，但 in-app browser 的下载事件未返回可核对的文件；文件选择与磁盘下载→重新打开的浏览器闭环**未验收**，不能把提示当作已经落盘。文件序列化/损坏拒绝/恢复及不重执行 SQL 的程序测试已通过，但仍需在真实导入环境核对下载文件和重开。没有为了凑验收读取页面内部控制器或伪造下载结果。临时验收标签与本地服务已关闭，用户 SillyTavern 标签保留。
