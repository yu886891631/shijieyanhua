  提供统一九页面外壳：总览、世界资料、楼层记录、世界书投影、API 配置、自动演变、填表提示词、备份与迁移、外观与显示。

- 默认淡绿普通区域，危险操作用淡粉；保留奶油、淡粉、深色主题。成功、等待、警告、危险都有文字说明，不仅靠颜色区分。
- 15 个既有功能组件继承同一组语义颜色；独立使用时保留原样式回退。既有 API 页面沿用同一套色值别名，不建立第二套 API 数据或路由权威。
- 外观页提供 100/110/125% 界面字号、舒适/紧凑密度、长单元格限高/完整展开和恢复默认。当前仅保留于挂载实例，不写聊天或全局设置；持久化接入在 T15。
- 窄工作区按容器宽度改变导航、表组和表单布局；宽表只在自己的滚动区横向滚动，不撑开整页。内容与导航可独立滚动，关闭按钮不随内容滚出顶部。
- T11 页面增加可选嵌入模式，统一外壳内不再重复显示它自己的页面标题和顶层导航；独立模式保持原行为。
- 页面切换采用保留挂载方式，不销毁编辑草稿、不自动保存、不取消运行。外壳显示调用方提供的未保存范围，不猜测业务状态。
- 关闭有草稿时先展示危险确认；初始焦点为“留在工作台”，Escape 关闭确认并把焦点还给关闭按钮。明确请求关闭也只发出事件，不暗中保存、清草稿或取消任务。
- 类型化填写控件通过 `aria-describedby` 关联字段说明与错误，并保留错误文字、`aria-invalid`
  和首个无效字段定位。禁用态、等待确认态不伪装为已保存。
- 提供焦点可见、减少动画、系统强制色的样式支持；系统强制色与屏幕阅读器未在真实设备独立验收，不声称完整无障碍认证。

本轮没有改 SQL 权限、保存/锁定语义、宏观与微观流程、收费或世界书删除范围。

## 2. 独立浏览器验收方式

`t14-visual-server.mts`
是显式启动的开发服务器：仅监听 loopback，在内存编译，`write: false`，不会输出生产 dist。浏览器只请求本地视图夹具与脚本，CSP 禁止外部连接。

视图来自同一套本地 SQLite/模拟服务的安全快照；页面代理阻断业务写入和模型发送，不用假成功演示保存。API 页复用现有 Vue 组件，但仅在该组件的独立构建导入处替换为纯内存模块，不读取真实 Key、设置或工作流桥接。

验收页明确标注“不是酒馆导入包”。不能把它当成已安装新版酒馆工作台、真实保存、真实 API 请求或世界书写入的证据。

最终构建：

- 内存脚本：1,312,919 bytes，非生产压缩包体。
- 页面 `t14-build` SHA256：`f4787ecdc86c836472bbd7371b2646db58263dd0d0668767610d211ebaa5b897`。
- 此前完整几何矩阵构建：1,312,865 bytes；SHA256 `607281e750b1ef36a939de0eb9e0045b1086ebec95a8db26df2506c58e08437e`。
- 两次构建之间仅修正外壳危险确认按钮的颜色优先级，并为其增加已有测试内的断言；没有更改布局或业务代码。最终构建再次逐页、主题、窄屏、键盘和危险色复核。

本地截图发现并修正的两个问题：

1. 开发服务器曾使用文件名尾部生成 scoped 样式 ID，不同 Workbench 文件发生碰撞。现在按完整路径 SHA256 生成唯一 ID；该问题仅在新建的验收工具中，未修改生产 Vue
   loader。
2. 外壳普通按钮规则覆盖“仍请求关闭”的危险色。现在危险按钮的文字、背景和边框有明确优先级，四主题读回色值均符合语义色。

三类检查不能混为一谈：CSS
zoom 只是验收页模拟；界面字号是插件自己的阅读选项；viewport 是实际可用页面宽度。**本轮没有操作浏览器原生缩放，也没有通过 SillyTavern 宿主的 100/110/125% 缩放验收。**

键盘复核：

- 宽表使用 ArrowRight 从 `scrollLeft=0` 到 `40`，内容保持局部滚动。
- 主内容可用 Control+End 到达“暂存修改与保存”，关闭按钮仍位于外壳顶部。
- 草稿关闭确认初始焦点：“留在工作台”；Escape 后焦点：“关闭工作台”。
- 组件测试确认跨页返回保留已填写草稿，不发出保存、丢弃或关闭事件；错误描述关联、首个无效字段定位和取消不保存均通过。

验收工具最终日志没有应用运行错误；有一条 Vue esm-bundler 开发构建 feature
