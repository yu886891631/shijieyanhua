## 4. 真机验收清单

请在 SillyTavern 中按顺序执行：

1. 先确认 alpha.11 和 alpha.12 已停用，不要同时启用多个世界演变控制台版本。
2. 导入 alpha.13 测试包，确认导入后仍为关闭状态，脚本名称包含 `A0.1.0-alpha.13`。
3. 启用 alpha.13，打开“世界演变控制台”。
4. 进入“演变配置 → API 配置”，确认独立 API 页面能够打开，已有配置仍在，Key 仍显示为脱敏状态。
5. 切换到“自动演变”，确认页面只保留运行控制、候选数量、重试和 API 状态摘要，不再出现重复 API 编辑表单。
6. 返回 API 页面再切回自动演变，确认配置和运行设置没有丢失。
7. 点击“模拟连接测试”，确认出现本地模拟成功结果；不要点击真实运行、自动运行或会消耗额度的按钮。
8. 在常规窗口、窄窗口和 110%/125% 缩放下检查：页面不横向溢出，长预设名可换行，按钮可点击，数据库/世界书页面不被挤压。
9. 停用 alpha.13，重新启用 alpha.12；确认旧控制台可以打开，作为回退路径。

若出现页面打不开、配置异常或数据库显示异常：立即停用 alpha.13，保留截图和控制台日志；不要清空聊天、IndexedDB、数据库或角色卡世界书。
