# 世界演变 A0.1.0-alpha.12 API 内置化真机验收

本包用于验证世界演变控制台的内置 API 配置和 S5/S6 路由接入。它默认关闭，不会自动运行世界演变，也不会在导入时调用真实 API。

## 导入前

1. 保留 alpha.11，不要删除它、聊天记录、世界演变数据库或角色卡世界书。
2. 如果 alpha.11 当前已启用，先停用它；同一时间只启用一个世界演变控制台版本。
3. 导入：

   `导入到酒馆中/酒馆助手脚本-世界演变控制台-A0.1.0-alpha.12-API测试版.json`

## 第一轮：不访问网络的页面验收

1. 确认新脚本名称带有 `A0.1.0-alpha.12`，且导入后仍为关闭状态。
2. 启用 alpha.12，打开“世界演变控制台”。
3. 打开“API 配置”页，确认显示 `内置 API 配置` 和 `BUILT-IN API · ALPHA.12`。
4. 新建一个仅用于测试的预设，填写任意本地测试名称、模型、Endpoint 和占位 Key；不要保存真实 Key 到截图或日志。
5. 点击“模拟连接测试”。按钮应显示本地模拟成功，不应产生网络请求或额度消耗。
6. 保存预设、设置主 API、查看备用路由顺序，再刷新页面确认配置仍在。
7. 确认状态摘要只显示“Key 已配置/未配置”，不显示完整 Key。

## 第二轮：只读数据与回退验收

1. 打开数据库页，确认原有楼层、revision、checkpoint 和世界书投影仍存在。
2. 不点击“手动运行”，不打开自动运行，不修改或删除旧楼层。
3. 停用 alpha.12，再启用 alpha.11，确认旧控制台仍可打开；这就是回退路径。

## 真实 API 验收（需要单独确认）

本导入包不会自动执行真实 API 测试。只有在确认 Endpoint、模型、Key 和额度后，才进行以下最小测试：

1. 先只点击一次真实连接测试；
2. 确认返回成功后，再手动执行一轮世界演变；
3. 检查数据库 revision 只增加一次，世界书投影与数据库一致；
4. 验收完成后关闭自动运行，保留 alpha.12 或回退 alpha.11。

## 失败处理

- 页面打不开：停用 alpha.12，重新启用 alpha.11。
- 配置显示异常：不要点击真实运行，保留控制台截图和浏览器控制台错误。
- 世界书投影失败：数据库已提交的状态不会自动回滚，可在控制台重试投影；不要重复调用 AI。
- 任何数据异常：先导出数据库备份，再停用 alpha.12；不要清空聊天或 IndexedDB。
