# 世界演变 A0.1.0-alpha.14 U0–U9 UI 测试包

本包用于在 SillyTavern 中检查工作台和备份/迁移页面。默认关闭自动演变，并在本测试脚本中关闭世界书自动同步；不会因启用脚本而自动调用 AI 或重建世界书。

## 重要的数据边界

- alpha.14 使用独立脚本 ID，但继续连接现有世界演变数据库；数据库格式保持 `A0.1.0-alpha.11`，与 alpha.13 等旧控制台共用同聊天 IndexedDB，不是沙盒。
- 本次只做页面查看。请勿点击“确认替换当前聊天数据库”“确认迁移此备份”“清空当前聊天数据库”，也不要手动运行世界演变或开启自动运行。
- 测试期间不要删除或 swipe 聊天消息；数据库监听会依既有逻辑对相关楼层做确定性重建。
- alpha.14 与 alpha.13 不要同时启用。保留 alpha.13 作为回退包，不要删除它、聊天、数据库或世界书。
- 不需要填写 API，也不需要做真实 API 测试。不要在截图或日志中暴露真实 Key。

## 页面检查步骤

1. 在酒馆助手脚本管理中导入：

   `导入到酒馆中/酒馆助手脚本-世界演变控制台-A0.1.0-alpha.14-U9测试版.json`

2. 确认新脚本名为 `世界演变控制台（A0.1.0-alpha.14 U9 UI 测试版）`、默认关闭，并先停用 alpha.13（不要删除）。
3. 启用 alpha.14。通过顶部扩展菜单中的“世界演变控制台”打开工作台；确认版本显示 alpha.14。
4. 进入“备份与迁移”页，只查看当前聊天标识、revision、记录摘要、导出范围、旧版迁移说明和危险操作区的排版。
5. 页面外观无误后发一张截图即可。若要检查导入或迁移预览的实际显示，请先告知我；预览读取的是你选择的文件，仍不要点最后的确认按钮。
6. 检查完成后停用 alpha.14。若要重新使用 alpha.13，先确认它自己的自动同步/自动运行设置；旧版本默认设置与本测试包不同。

## 回退与问题反馈

- 页面未打开或报错：停用 alpha.14，保留页面截图与控制台错误；不要清库或重复导入。
- 本包没有自动发布稳定版；测试结果确认后再决定是否进入 U10 全局回归和后续正式发布。
