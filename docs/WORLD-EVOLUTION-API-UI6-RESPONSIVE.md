# 世界演变控制台 UI-6 排版与响应式优化

> 完成日期：2026-10-01

> 基线提交：`716af88`
> 状态：UI-6 已完成，下一阶段为 UI-7 测试、构建与发布候选

## 1. 本阶段目标

收口 API 配置页和自动演变页的宽度、滚动、窄屏、缩放与主题适配问题；不改变 API、数据库、世界书投影或运行路由。

## 2. 已完成修改

修改文件：

```text
src/世界演变/console/Workspace.vue
src/世界演变/console/ApiSettingsPanel.vue
src/世界演变/ui.ts
```

- 页面滚动区域禁止横向溢出，并使用稳定滚动槽和边界滚动行为；
- API 页面和自动演变页面设置独立最大宽度，保留数据库内嵌面板的宽度行为；
- API 表单增加 `border-box` 和最小宽度约束，输入框不会因宿主样式撑出网格；
- API 表单、路由区和自动演变状态卡使用容器查询，按实际可用宽度切换多列、双列和单列；
- 窄屏下 API 操作按钮自动换行，超窄窗口改为整行按钮；
- 自动演变运行设置在窄容器下改为单列字段，避免重试和稳定楼层参数错位；
- 移动端工作台取消额外缩放变换，避免 110%/125% 设置导致整页裁切；
- 长预设名和路由摘要允许断行，顶部标题和面包屑支持省略；
- 状态卡、主按钮和标签颜色改用工作台主题变量，兼容浅色、深色、奶油风和地雷色。
